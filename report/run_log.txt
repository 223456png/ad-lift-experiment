[4] 依从性与曝光内生性（本实验最关键的归因环节）
==========================================================================
  组                                n     visit      conv
  control                  2,096,937   3.8201%   0.1938%
  treated_exposed            428,212  41.4538%   5.3784%
  treated_not_exposed     11,454,443   3.4861%   0.1194%

  ▼ 陷阱演示
    exposed vs control：visit 3.82% → 41.45%（10.9 倍）
    未曝光组 vs control：visit 3.82% → 3.49%（0.91 倍）
    → 同样没看到广告的人，被分到 treatment 组后 visit 反而更低
      => 曝光分配存在明确的选择效应，exposed vs control 的差值是混杂结果，不是因果效应

  ▼ 三个口径（以 conversion 为例）
    ITT          = +0.001152 （相对 +59.4%）  ← RCT 保证无偏，用于决策
    Wald CACE    = +0.031964 （相对 +1549.7%）  ← 需 monotonicity + 排他性
    naive exposed= +0.051847 （相对 +2675.8%）  ← 有偏，不可用
    P(曝光|treatment) = 3.6037%，即 96.40% 的投放预算落在未曝光人群

[7] 收益验证：每曝光用户的成本上限（反向推导）
==========================================================================
  ⚠ 数据限制：每行是一个 user，exposure 是用户级 0/1 标志
     → 没有曝光次数、没有单次曝光成本，绝对 CPM / ROI 无法从数据推导
     → 下面只做反向推导：盈亏平衡时，每个被曝光用户最多能花多少

  参数假设：AOV=200.0 元  毛利率=30%  单均毛利=60.00 元
  增量转化     = 13,687 单
  增量毛利     = 821,239 元
  被曝光用户   = 428,212 人（user 级，不是曝光次数）
  >>> 盈亏平衡的「每曝光用户成本」上限 = 1.92 元/人
      超过这个数就亏。这是给运营的投放单价天花板。

  反过来：如果每曝光用户成本是 C 元，则总成本 = C × 428,212
         每用户成本             总成本         CPA       ROI      结论
           0.5         214,106       15.64      3.84      可行
           1.0         428,212       31.29      1.92      可行
           2.0         856,424       62.57      0.96      亏损
           4.0       1,712,848      125.14      0.48      亏损
           8.0       3,425,696      250.28      0.24      亏损

  口径提醒：增量转化的分母是全部 11,882,655 个 treated 用户，
            不是 428,212 个被曝光用户——因为曝光本身受依从性影响。
